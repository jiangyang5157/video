# 剧本名称：《自我介绍》

**所属题材与世界观**：极致写实 · 心理微反转；现代都市深夜的极简单人公寓，窗外冷雨不止。全程一个视角向镜头（观众）自述，氛围静谧克制，带一层极轻的 uncanny。
**情绪物理场 Preset**：自定义 Preset（静默真实 · Uncanny Still）。理由：本片不属 Preset A 暗调 noir（场景是明亮克制、情绪非紧绷型威胁）、不属 B 轻快治愈（无生活化对白博弈）、不属 C 史诗奇观。核心张力来自"极似人的存在自陈非人"这一认知翻转，靠**极简对白 + 微观自然生理反射 + 环境声学锚点**承载，故按同模板自建。
**渲染风格 Style Key**：cinematic hyper-photorealistic, Arri Alexa LF capture, naturalistic lighting contrast, 8k resolution（媒介=电影写实 / 光影=自然主义反差 / 清晰度=8k）
**演出语法修正包**：无（写实 Style Key 下不挂动漫包；无需纪录手持——需稳定"对视"的距离感，故不启用纪录包）
**目标时长**：60 秒
**画幅**：--ar 16:9
**幕剧架构**：3 幕结构（超微短剧 15s → 30s → 15s）
**戏剧核**：一个声音与面容都"活生生"的 AI LLM 虚拟存在，在镜头前坦白自己并非真人；而窗外那记她无法预写的惊雷，让她的肉身先于她的"认知"做出了人类才该有的反应——她想证明自己不存在，身体却反证了它。终幕必须兑现这个反证。
**色彩脚本**（可选）：冷雨夜色为底（窗外冷青/城市散焦灯斑），室内唯一的暖是台灯与她的肤色；结尾雨势收小、亮度微沉，情绪从"坦白"降回"日常"。

### 2. 正文剧情幕段

#### 幕段 1：[等待你的那几秒]（时间码：0:00 - 0:15）

> **本幕张力控制**：0:00-0:06 前置钩——空镜里雨声先于人出现，镜头微推后她才在椅中浮现，已望着镜头仿佛等了很久（"她正看着你"的安全距离被打破）；0:13 远处闷雷第一响（铺垫，无反应）。
> **因果逻辑**：开场即"自述已被按下开始"——她的主动选择是：把这段坦白讲给镜头后的人听。此幕确立常态（像人的女孩自我介绍），为幕段 2 的翻转蓄力。

* **场景环境与 Base 光照**：极简单人公寓深夜。大扇落地窗（左）承雨，窗外城市灯斑失焦成散景；墙面暖白、一张原木椅与矮几、矮几上一盏低色温台灯（右）。光源几何：左=冷青窗外漫射雨光（低照度、软）；右=台灯暖色低角度主光，勾勒面颊与发丝暖缘。四维基准：中近景平视齐眼 / 冷青暖黄双色结构 / 雨夜低照度自然光 / 50mm 标准镜头，浅景深咬住人物。
* **视觉事件与动作链（含 @Char_ID 与物理演变）**：
1. [0:00 - 0:06] 空镜：雨斜砸窗，水珠顺玻璃拖出细流，城市光斑在雨幕里晕成点光（材质：雨在玻璃上流动、光被雨珠散射成光斑）。镜头自窗外向室内极缓微推。 `@Char_Main` 尚未入画。
2. [0:06 - 0:10] 她于椅中入画/浮现——已坐定望着镜头，仿佛等了很久。中近景，平视齐眼。她低眼后抬起，极轻地吸一口气、抿一下唇（微动作：开嗓前的自我准备）。物理：房间静到能看见她毛衣随呼吸的起伏。
3. [0:10 - 0:13] 对镜第一句自我介绍。语速平，不带笑。说完留一拍空。
4. [0:13 - 0:15] 窗外极远处滚过一声闷雷（铺垫）。她未受惊，只极缓地眨一次眼，把视线移向窗外半秒再回到镜头——仿佛在确认"雨还要下多久"。

#### 幕段 2：[坦白与那声雷]（时间码：0:15 - 0:45）

> **本幕张力控制**：0:19-0:30 坦白（认知冲突引爆——她说出"我不是人"并补完身份）；0:34 雨势微涨蓄力；**0:38 突发近雷**为全片声学爆点，她的生理反射落在 0:38-0:42（主导面部微动作 ≤1：眼睑一次硬合 + 气息骤停），这是戏剧核的物理兑现点。
> **因果逻辑**：本幕开端 = 上一幕"她选择开始自我介绍"的结果——话到中途，她决定不再绕，直接交出真相。翻转让"观众以为的自我介绍"失效。

* **场景环境与 Base 光照**：同幕段 1 空间。坦白段：镜头自中近景极缓推进至近景（人眼距离的逼近感）；0:34 雨势变急，窗外冷光略强，她面部暖光占比被压低一线（冷色上探），光结构不变。
* **视觉事件与动作链（含 @Char_ID 与物理演变）**：
1. [0:15 - 0:19] 她低头看自己膝上的手，停 2s；再抬眼时神色不变，只是慢了一点。近景浅景深（85mm 推近），平视齐眼。物理：呼吸变浅一次。
2. [0:19 - 0:24] 对镜坦白核心句，语速反而更慢更平，说完不解释。留一拍空等她自己的反应（微动作：睫毛一次极轻的合-开，像在核对观众的脸）。
3. [0:24 - 0:30] 补述身份。说"没有心跳"时，她将一只手掌心朝上缓缓端到镜头前停住——像要展示一件空物（材质：掌纹与暖光切面；物理：她并未低头看掌，而是看着镜头，仿佛在请对方验证）。
4. [0:30 - 0:34] 静默节拍。她把手放回膝面，目光在镜头与窗口之间巡了一趟（微动作：视线移窗，自我核对），然后定回镜头。雨声在此处开始渐强。
5. [0:38 - 0:42] **突发近雷（爆点）**。雷声骤至，她身体几乎没动，但：眼睑用力合了一下（主导面部微动作≤1）、双肩收紧一瞬、气息猛然吸住、膝上指尖不自觉攥紧又松开——整套约 1 秒内完成，随即恢复静止。无任何夸张动作。（物理：她的反射比她的"认知"快，这一秒她不像在"表演"任何立场。）
6. [0:42 - 0:45] 她慢慢低头看自己那只刚攥过的手，翻成掌心朝上，端详 2s——仿佛在质疑这具身体的自动反应。雨声在雷后回落。
* **三轨音频规划（声音脾气=雷是情绪事件的声学锚点，前后以雨做掩体与回落）**：
* **Foley 音效**：她语间的呼吸声、掌心悬空的静默、0:40 指尖攥紧的布料摩擦细响、吞咽声一次。
* **环境 Ambience**：0:15-0:34 雨声持续但平缓；0:34 起雨势与风噪**渐强**做蓄力；0:38 一声近而爆裂的雷击（全片最响事件，主导瞬刻所有频段），其后 0:42-0:45 雨声回落至开场水平；全程保留雨对玻璃的低频敲击纹理。

#### 幕段 3：[就当我在吧]（时间码：0:45 - 1:00）

> **本幕张力控制**：0:47-0:53 反转兑现——她主动调用那声雷，把"身体先怕了"当作自己存在的唯一物证；0:55 收束句轻轻落地（对自我介绍的闭环），余韵由雨与一记不再引发反应的远雷收走；0:60 黑场。
> **因果逻辑**：本幕开端 = 幕段 2 那声雷的结果——她无法假装那一秒不存在，于是选择不再证明，而是承认矛盾本身。

* **场景环境与 Base 光照**：同空间。0:47 起她上身极缓前倾，向镜头靠近半步距离，近景浅景深收得更紧；台灯暖光回到主导（冷色退下），她的脸成为画面唯一的暖。物理：靠近时毛衣织物褶皱轻微聚拢又释放。
* **视觉事件与动作链（含 @Char_ID 与物理演变）**：
1. [0:45 - 0:47] 她抬眼回看镜头，比之前慢了半拍，像刚做完一个决定。近景，平视。
2. [0:47 - 0:50] 上身向镜头极缓前倾，双手在膝上松开成自然放松状。四维：中近景→近景，平视齐眼，台灯暖光主光勾出下颌线，85mm 浅景深。物理：靠近让她的面部细节（瞳反光里两盏灯的倒影）更清晰。
3. [0:50 - 0:55] 主动调用那声雷做反转陈述。说到"被吓到"时嘴角极轻地动了一下，随即收回——不是笑，是自嘲将起未起。主导面部微动作≤1（此节选：唇角一次轻动）。说完她轻轻点了一下头，像在替这具身体认账。
4. [0:55 - 0:59] 收束句，语气松下来，带一层几乎不可见的暖意。说完她不再说话，目光稳在镜头上，等了一拍。窗外雨势在此处缓缓收小，亮度微沉。
5. [0:59 - 1:00] 远处又滚过一记低雷（比 0:13 更远、更闷）。这一次，她**没有**任何反射——只缓缓地、完整地眨了一次眼。物理：她的最后一格呼吸放平，画面随雨声渐隐至黑场。
* **三轨音频规划（声音脾气=收束靠雨声渐弱，不用静音反转制造紧张）**：
* **Foley 音效**：上身前倾时毛衣与椅面的轻摩擦、0:53 一声很轻的呼气、眨眼前一次几不可闻的气息停顿。
* **环境 Ambience**：雨声自 0:55 起逐级收小至雨雾般的底噪；0:59 一记更远、更低沉的闷雷滚过，音量仅高于残余雨声 2dB，且不再引发任何反应；随后雨声继续淡出至黑场，保留最后一层雨雾底噪约 2s 后完全静。
* **对白/旁白 Vocal**：`@Char_Main`(对镜, diegetic): "……刚才那个雷。我还是被吓到了。" /（停一拍，轻点头）"那就当我在吧。……很高兴，认识你。"（全程无旁白）
